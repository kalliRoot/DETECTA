# 🕵️ DETECTA

**DETECTA** é uma ferramenta forense que analisa microexpressões faciais e voz para identificar padrões de verdade e mentira em tempo real.

---

## 🧠 Como funciona

- **Rastreamento facial**: 468 pontos faciais são mapeados em tempo real.
- **Análise de microexpressões**: Detecta movimentos sutis de olhos, boca e sobrancelhas.
- **Análise de áudio**: Monitora volume e tom de voz.
- **Relatório automático**: Gera um relatório detalhado ao final do teste.

---

## 🚀 Tecnologias

- HTML5 / CSS3 / JavaScript
- [MediaPipe FaceMesh](https://developers.google.com/mediapipe/solutions/vision/face_landmarker)
- Web Audio API
- Canvas 2D
